# Experiment Plan

**Problem**: 设置一个三区域两两互联的低空单层流量规划与闭环控制仿真场景，并将所有实验参数，尤其是需求参数，显式写出。  
**Method Thesis**: 在三区域完全互联且六个有向 OD 需求均为正的场景中，如果静态聚合通量守恒、目标位于 MFD 自由流分支、各执行容量有裕度、且内部转移矩阵 `B` 满足 `rho(B)<1`，则手稿提出的起飞准入与边界放行闭环应在目标附近表现出局部指数稳定。  
**Date**: 2026-05-30  
**Manuscript Source**: `drafts/LAATDraft_v1.3.tex`

## Claim Map

## Paper Storyline

- Main paper must prove: 在一个完全互联的三区域单层低空网络中，静态 OD 需求可以清楚地聚合为守恒区域通量；在 `rho(B)<1` 与局部未饱和条件下，闭环误差按指数衰减。
- Appendix can support: 高需求压力、无离网流反例、远初值饱和、采样保持离散实现。
- Experiments intentionally cut: 多高度层、飞行时延、起降场排队、逐目的地组分状态、在线重路由、大规模 MPC、真实城市标定。
- Frontier contribution: 本手稿不是 LLM/VLM/Diffusion/RL 方法，因此不设置 frontier necessity 实验。

## Experiment Blocks

### Block 1: Fully Connected Demand Aggregation and Feasibility

- Claim tested: C1.
- Why this block exists: It checks whether six positive OD demands in a fully connected three-zone low-altitude network can be converted into the manuscript's aggregate static variables without ambiguity.
- Dataset / split / task: deterministic synthetic OD table above; no train/test split.
- Compared systems: proposed aggregate planning interface only.
- Metrics:
  - Static conservation residual.
  - Nonnegativity of `q^g,T,T_0`.
  - `beta` normalization residual.
  - MFD target residual `max_i |bar u_i G_i(bar n_i)-Lambda_i|`.
  - Takeoff and interface capacity margins.
- Setup details:
  - Use the exact OD table and direct paths in Section 2.
  - Compute `q^g,T,T_0,Lambda,beta,beta_0,B,bar n`.
- Success criterion:
  - Conservation and normalization residuals `<=1e-10`.
  - Target residual `<=1e-8`.
  - All capacity margins strictly positive.
- Failure interpretation:
  - Any failure means the scenario does not validly enter the dynamic theorem.
- Table / figure target:
  - Main paper table: fully connected OD demand and aggregation result.
- Priority: MUST-RUN.

### Block 2: Local Stability Under Fully Coupled `B`

- Claim tested: C2.
- Why this block exists: It validates the theorem on a genuinely coupled `B`, rather than a triangular or chain network.
- Dataset / split / task: same fully connected scenario; local perturbation runs R004-R006.
- Compared systems:
  - Nonlinear closed-loop ODE with saturation operators.
  - Exact unsaturated linear oracle `dot e=Ae`.
- Metrics:
  - `rho(B)`.
  - eigenvalues of `A`.
  - final error ratio.
  - fitted log-error slope.
  - saturation fraction.
  - capacity violations.
  - nonlinear-vs-linear oracle mismatch.
- Setup details:
  - Use controller and solver parameters in Sections 6-7.
  - Save trajectory CSV and log-error figure for each local run.
- Success criterion:
  - `rho(B)<1`.
  - `max Re(lambda(A))<0`.
  - saturation fraction `0`.
  - final error ratio `<=0.05`.
  - oracle mismatch `<=1e-3`.
- Failure interpretation:
  - Saturation means the trajectory left the local theorem region.
  - Oracle mismatch without saturation indicates a controller/sign/indexing bug.
- Table / figure target:
  - Main paper figure: regional accumulations and log error norm.
- Priority: MUST-RUN.

### Block 3: Explicit Failure and Boundary Checks

- Claim tested: C3.
- Why this block exists: It ensures the result checker refuses to overclaim invalid cases.
- Dataset / split / task:
  - `R007`: fully connected no-exit internal circulation, `T_ij=0.10` for all `i!=j`, `T_i0=0`, `q_i^g=0`; expected `rho(B)=1`.
  - `R008`: base demand table scaled by `s=2.10`; expected to violate MFD capacity because `Lambda_2=Lambda_3=0.903>0.90`.
  - `R009`: base scenario with far initial condition `e(0)=(+8,-2,+8)`; expected to trigger saturation.
- Compared systems: valid base scenario vs. each invalid stress scenario.
- Metrics:
  - Failed assumption labels.
  - `rho(B)` for R007.
  - MFD capacity margin for R008.
  - saturation fraction for R009.
- Setup details:
  - These stress runs are diagnostic, not performance comparisons.
  - A stress run is successful only if it is rejected with the expected label.
- Success criterion:
  - R007 -> `ASSUMPTION_FAILURE`.
  - R008 -> `ASSUMPTION_FAILURE`.
  - R009 -> `OUTSIDE_LOCAL_REGION`.
- Failure interpretation:
  - If any invalid run is labeled as theorem support, the checker is unsafe.
- Table / figure target:
  - Appendix assumption-failure matrix.
- Priority: MUST-RUN.

### Block 4: Sampled-Hold Robustness

- Claim tested: C2 support only.
- Why this block exists: If the implementation uses sampled commands, continuous-time stability should not be silently overclaimed.
- Dataset / split / task: valid fully connected scenario.
- Compared systems:
  - Continuous linear oracle.
  - Euler sampled update for `Delta t in {0.05,0.10,0.25,0.50}`.
- Metrics:
  - `rho(I+A Delta t)`.
  - final error ratio.
  - half-step sensitivity for `Delta t=0.05`.
- Setup details:
  - Use the same `A` from Section 6.
- Success criterion:
  - `rho(I+A Delta t)<1` for checked steps.
  - half-step sensitivity `<=1e-3`.
- Failure interpretation:
  - Failure indicates numerical discretization risk, not a failure of the continuous theorem.
- Table / figure target:
  - Appendix sampled-implementation table.
- Priority: NICE-TO-HAVE.
